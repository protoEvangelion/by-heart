# Today (app shell + daily set)

Scope: the installed app's home surface, and the recitation cover it opens. Visitor mode: Operate.
Audience: one person working through the Topical Memory System; phone in a dark room or an iPad at a desk.
Job: know what is due, then recite it exactly.

## Direction contract

THESIS: A scripture memory trainer written in the notation language of a shape-note hymnal, where recall is verified letter by letter against the LSB text. It refuses the category's streak dashboard: no hero metric, no progress ring, no card grid of features.

OWN-WORLD: Night hymnal. Ink ground #0A0E1A, bone text #EDE7DA, brass #E5B665, sage #8FC3AC, rubric #E6857A, hairlines at 10% bone. Besley for the tune-name voice, Literata for scripture, Hanken Grotesk for the working UI. The four solfege shapes (diamond, square, oval, triangle) are the product's entire state alphabet, drawn as geometry, never as icons.

STORY: The user sees what the schedule owes today, recognizes the verse as a proof line with its consonants removed, taps Begin, types it, grades it, and watches the shape sheet add a mark. Nothing to decide except the grade.

FIRST VIEWPORT: Date line under a book-title "Daily set". One card holds the count ("2 verses to recite"), the first verse as a masked proof line in brass-ruled blanks, and the Begin button as the only bright object. Below it, "The sixty": five ruled rows, one per TMS series, each carrying twelve solfege marks that encode that verse's stage.

FORM: grounded direction 5 of 7 (shape-note hymnal), seed reference 0bff714b628a8bcb.

RAISES: from rw-centre-rail-reference-setting (declined, competitive): the ruling discipline, every rule and blank drawn at one device pixel from live layout, never a decorative underline. From wayfinding-cartography-signage-midnight-transit-diagram (declined): never shrink the whole network; the daily set is a corridor, one series at a time inside the recitation cover, not sixty rows at once.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
